yap brings the same push-to-talk model to Linux. A daemon keeps the speech model warm, so transcription lands in about 200ms on an ordinary CPU — CUDA is optional, not required. Its keystroke-first design types the result rather than relying on app integrations, which is why it works where other dictation tools fail: terminals, Electron apps, and remote sessions. Install is a one-line bootstrap.
